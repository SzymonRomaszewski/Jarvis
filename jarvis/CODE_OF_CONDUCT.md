# Code of conduct

This project is for building something useful and enjoyable together. To keep it that way:

- Be kind and patient. Assume good intent, especially with newcomers.
- Keep feedback about the work, not the person.
- No harassment, discrimination, or personal attacks of any kind.
- Respect other people's time: search existing issues first, and give enough detail to reproduce a problem.

Maintainers may edit or remove comments, issues and contributions that break these rules, and may ban people who repeatedly do. To report a concern, contact the maintainer privately through their GitHub profile.
